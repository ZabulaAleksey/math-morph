# Дизайн и UI/UX

## Текущее состояние

Пользовательский интерфейс ещё не реализован, а визуальная система владельцем продукта не утверждена. Канонические tokens, typography, colors, spacing и reusable-компоненты пока отсутствуют.

До появления утверждённого дизайна разрешён только технический, визуально нейтральный каркас без нового visual language. Перед первой содержательной UI-реализацией этот документ должен быть дополнен фактическими требованиями или утверждённым design contract.
